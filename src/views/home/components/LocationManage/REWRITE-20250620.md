# 原料仓位管理页面重写 - 修改步骤总结

## 📊 数据库表结构分析结果

### 核心表关系
```
Warehouse (仓库) 
    ↓ (1:N)
Location (库位) 
    ↓ (1:N) 
Inventory (库存记录)
    ↓ (N:1)
RawMaterial (原材料)
```

### 关键字段映射
- **Location表**: LocationID, WarehouseID, LocationName, LocationType, Zone, Row, Col, Level, Capacity, CurrentOccupancy, IsOccupied, Status
- **Inventory表**: 通过LocationID关联，存储实际库存数据
- **实现逻辑**: Location存储库位基本信息，Inventory存储具体的原材料库存

## 🚨 重要注意事项

### 1. **数据兼容性**
- 新系统基于Location表，原有基于Inventory表的数据需要迁移
- 需要运行占用情况刷新接口更新CurrentOccupancy字段

### 2. **权限控制**
- 所有API接口都需要认证Token
- 建议添加操作日志记录

### 3. **性能优化**
- 库位列表查询包含复杂关联，建议添加数据库索引：
```sql
CREATE INDEX idx_location_warehouse ON Location(WarehouseID, Status);
CREATE INDEX idx_inventory_location ON Inventory(LocationID, CurrentQuantity);
```

### 4. **错误处理**
- 删除库位前检查是否有库存
- 更新状态时验证业务规则
- 批量操作提供详细的成功/失败信息
