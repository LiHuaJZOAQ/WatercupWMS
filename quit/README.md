# Redundant Files Archive

This directory contains redundant backup files, generated test reports, and temporary scripts used during the development process. These files have been moved here to clean up the project structure and prevent any interference with the main source code.

## 1. Hidden Backup Files
Files that start with `.` (e.g., `.MainView.vue`, `.index.js`). These are typically temporary or backup files generated by text editors or IDEs during development.
- `.index.js` / `..index.js` (Backend backups)
- `..request.ts` (API request backups)
- `.Review.vue` / `.RawMaterial.vue` / `.InboundOrderCreate.vue` (Inbound backups)
- `.InventoryRawMaterial.vue` / `..InventoryRawMaterial.vue` (Inventory backups)
- `.LocationRawMaterial.vue` / `..LocationRawMaterial.vue` (Location backups)
- `.MainView.vue` (MainView backups)

## 2. Temporary Execution Scripts
Node.js scripts (`*.cjs`) that were written and executed temporarily during the iteration process to batch-insert API logic or replace Vue components.
- `add-basic-data.cjs` (Script for basic data CRUD APIs)
- `add-finished-inbound-api.cjs` (Script for finished products inbound APIs)
- `add-outbound.cjs` (Script for outbound APIs)
- `add-stocktaking-api.cjs` (Script for stocktaking APIs)
- `add-supplier.cjs` (Script for supplier APIs)
- `add-system-api.cjs` (Script for system settings APIs)
- `replace-outbound-vue.cjs` (Script for outbound Vue component replacement)

## 3. Test Output (`dogfood-output/`)
The `dogfood-output` folder contains QA test reports and screenshots generated by the `agent-browser` dogfood testing tool during systematic exploratory testing.
