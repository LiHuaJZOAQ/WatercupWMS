# WMS 需求分析说明书 (Requirement Analysis Document)

## 1. 项目背景
本项目最初为“水杯生产企业仓储管理系统 (Water Cup WMS)”，旨在管理制造型企业内部的原材料采购入库、生产领料出库、成品入库及发货出库等仓储环节。

## 2. 核心模块需求
1. **基础数据管理 (Master Data)**
   - 供应商、客户、加工厂、部门的管理。
   - 原料与成品档案字典管理。
2. **入库管理 (Inbound)**
   - 支持原料和成品的入库单创建、修改、作废。
   - 支持多级审核（草稿 -> 待审核 -> 已完成）。
   - 审核通过后，触发库存增加逻辑。
3. **出库管理 (Outbound)**
   - 支持原料领用、成品发货。
   - 支持出库单审核与预扣减。
   - **创新功能**：智能波次拣货 (Wave Picking)，支持将多个出库单聚合成一个波次，提高拣货效率。
4. **库位与库存管理 (Inventory & Location)**
   - 库位（排-列-层）的三维坐标管理与占用率状态维护。
   - 库存余量实时查询。
5. **盘点管理 (Stocktaking)**
   - 盘点单生成与实际库存录入。
   - 审核差异后自动生成盘盈/盘亏流水平账。
6. **通用辅助功能**
   - **导出功能**：支持将各类单据、库存明细导出为 Excel 格式报表（使用 `exceljs`）。
   - **打印功能**：支持生成标准 A4 打印单据（如入库交接单、拣货单），直接唤起浏览器打印机。
   - **移动扫码 (PDA)**：提供浏览器端的移动工作台，模拟扫码枪解析库位码、物料码和单据号。

## 3. 非功能性需求
- **安全性**：全站接口接入 JWT (JSON Web Token) 拦截校验；使用 bcrypt 加密密码。
- **性能**：支持长列表的分页查询，使用 InnoDB 事务（`BEGIN...COMMIT`）保障高并发下库存操作的 ACID 一致性。
